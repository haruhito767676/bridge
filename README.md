# Bridge

**Mac / Windows 間でファイルとクリップボードを全自動共有する、画面端常駐型のファイルシェルフ**

Bridge は画面右端に「つまみ」として常駐し、マウスを寄せるとスライドして現れる Yoink 風のファイルシェルフです。ファイルの一時置き場・クリップボード履歴・マルチデバイス同期の 3 つの機能をひとつの UI に統合しています。外部依存パッケージはゼロ（Electron 本体のみ）で、同期もクラウドを介さない LAN 内 P2P で完結します。

## 主な機能

### 1. ファイルシェルフ（一時置き場）
- Finder / エクスプローラーからのドラッグ & ドロップでファイルを一時保持
- Web ブラウザから画像やリンクをドロップ → 自動ダウンロードして実体ファイル化
- 選択テキストのドロップ → `snippet_*.txt` として自動保存
- リストからの **OS ネイティブドラッグアウト**（複数選択対応、Finder ライクな矩形選択・Shift/⌘ 選択）
- クリックで「本物のファイル」としてクリップボードへコピー（macOS: `public.file-url` / Windows: `CF_HDROP`）→ Finder / エクスプローラー / チャットアプリに ⌘V / Ctrl+V でペースト可能
- スペースキーで macOS 純正クイックルック

### 2. クリップボード履歴
- テキスト・画像・ファイルコピーをバックグラウンドで常時監視（500ms ポーリング）
- テキストは生データ + 裏生成 `.txt` の「二刀流」で保持 → クリックで即ペースト、ドラッグでファイル化
- 画像コピーは即 PNG 化してサムネイル表示・ドラッグアウトに対応
- Finder / エクスプローラーでの「ファイルのコピー」も検知してシェルフへ自動追加
- 同一内容の再コピーはカードを増やさず最上位へスタック
- ハイブリッド上限（テキスト 100 件 / 画像 30 件）+ あふれた裏生成ファイルの自動ディスク削除

### 3. マルチデバイス全自動同期
- 各デバイスが軽量 HTTP サーバー（ポート `9095`、`node:http` のみ）を持つ P2P 構成
- ピアは **同一 /24 サブネットの自動スキャン** + 静的設定（`sync-config.json`）で発見
- 新着は即時プッシュ、取りこぼしは 20 秒間隔の差分ポーリング（タイムスタンプ比較）で回収
- 3 台以上のメッシュ構成では中継転送により、直接つながっていないピアにも伝播
- 共有シークレットトークンによる認証（不一致は全エンドポイント 401 遮断、`timingSafeEqual` 比較)
- フォルダは自動で `.zip` 化してから転送
- 外部デバイス由来のアイテムには出身デバイス名バッジを表示（OS ごとに色分け）

### 4. スマート検索
- 展開のたびに検索バーへ自動フォーカス、そのまま打ち始められる
- `:` 入力で `file` / `clip` のフィルターサジェスト → Tab / Enter でバッジ化して種別絞り込み + キーワード検索

## セットアップ

```bash
npm install
npm start          # 開発起動 (electron .)
```

> **Windows での起動時の注意**: 環境変数 `ELECTRON_RUN_AS_NODE` が設定されているシェルからは GUI が起動しません。設定されている場合は解除してから `npm start` してください。また多重起動はシングルインスタンスロックにより 2 つ目が即終了します。

### ビルド

```bash
npm run build        # 現在の OS 向け (Windows: NSIS / Linux: AppImage)
npm run build:mac    # macOS 向け DMG
```

成果物は `dist/` に出力されます。

## 使い方

1. 起動すると、マウスカーソルがあるディスプレイの**右端中央に幅 15px の「つまみ」**が現れます
2. つまみへマウスを寄せる、またはファイルをドラッグして近づけると、幅 320px のシェルフがスライド展開します（マルチモニター対応: どのディスプレイの右端でも反応）
3. ファイル / 画像 / テキストをドロップして一時保持、クリックでコピー、ドラッグで取り出し
4. マウスが離れると自動で格納されます

### bridge:// URL スキーム

外部アプリ（macOS のクイックアクション等）からアイテムを追加できます。

```
bridge://add?path=/absolute/path/to/file    # ローカルファイルを追加
bridge://add?text=https://example.com/x.png # URL → ダウンロードして追加
bridge://add?text=任意のテキスト              # テキスト → .txt 化して追加
```

## デバイス間同期の設定

初回起動時に `userData` ディレクトリへ `sync-config.json` が自動生成されます。

- macOS: `~/Library/Application Support/bridge/sync-config.json`
- Windows: `%APPDATA%\bridge\sync-config.json`

```json
{
  "port": 9095,
  "peers": ["192.168.1.23", "192.168.1.40:9095"],
  "autoScan": true,
  "myDeviceName": "Win-Desk",
  "secretToken": "全デバイスで同じ値に揃える共有キー"
}
```

| キー | 説明 |
|---|---|
| `port` | 同期サーバーの待ち受けポート（既定 `9095`） |
| `peers` | 静的ピア指定（`host` または `host:port`）。自動スキャンで見つからないセグメント越しのピア用 |
| `autoScan` | 同一 /24 サブネットの自動スキャン（既定 `true`、5 分間隔） |
| `myDeviceName` | バッジに表示される自デバイス名（省略時は `os.hostname()`） |
| `secretToken` | **同期認証キー。同期させたいデバイス全台でこの値を手動で一致させてください。** 未設定なら初回起動時に暗号学的乱数で自動生成されます |

トークンが一致しない相手からのリクエストは全エンドポイントで 401 遮断されるため、同一 LAN に他人の Bridge がいても履歴が混線・漏洩することはありません。

## プロジェクト構成

```
bridge/
├── main.js        # Main プロセス: ウインドウ管理・クリップボード監視・同期サーバー/クライアント
├── preload.js     # contextBridge による安全な IPC API の公開 (window.bridge.*)
├── renderer.js    # Renderer: リスト UI・検索・選択・D&D・履歴管理
├── index.html     # UI 骨格 (CSP 付き)
├── styles.css     # Apple ライクなすりガラス UI (ライト/ダーク対応)
└── package.json   # electron-builder 設定 (bridge:// スキーム登録を含む)
```

アーキテクチャ・プロトコル・IPC API の詳細仕様は **[SPEC.md](SPEC.md)** を参照してください。

## 設計上の要点

- **セキュリティ**: `contextIsolation: true` / `nodeIntegration: false`。Renderer は `preload.js` が公開する最小限の API のみ使用。CSP で外部リソース読み込みを遮断
- **ディスク保護**: 裏生成ファイル（`clipboard_*.png` / `snippet_*.txt` / 同期受信ファイル / 自動生成 zip）は `sessionTempFiles` で追跡し、履歴あふれ時と終了時に自動削除。**ユーザー自身がドロップした実ファイルには絶対に触れない**
- **耐障害性**: Renderer クラッシュ時は自動リロード復帰、準備前に届いたアイテムはキューイング。同期のファイル転送失敗はタイムスタンプを進めず次回ポーリングで自動再試行
- **省メモリ**: 同期のファイル転送は送受信ともストリーミング（数 GB でもメモリを圧迫しない）

## 既知の制約

- Windows のエクスプローラーでの複数ファイルコピー検知は、クリップボードフォーマットの制約（`CF_FILENAMEW` は 1 件のみ保持、Electron から `CF_HDROP` を読む手段がない）により**先頭の 1 件のみ**取得されます
- Finder 純正の「種類」ラベル（`mdls`）とクイックルックは macOS のみ。他 OS では拡張子ベースの表示にフォールバックします
- 同期はトークン認証付きですが平文 HTTP です。信頼できる LAN 内での利用を前提としています
