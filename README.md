# Bridge

**Mac / Windows 間でファイルとクリップボードを全自動共有する、画面端常駐型のファイルシェルフ**

Bridge は画面右端に「つまみ」として常駐し、マウスを寄せる（またはホットキーを押す）とスプリングでスライドして現れるファイルシェルフです。ファイルの一時置き場・クリップボード履歴・マルチデバイス同期の 3 つの機能をひとつの UI に統合しています。外部依存パッケージはゼロ（Electron 本体のみ）で、同期もクラウドを介さない LAN 内 P2P で完結します。

## 主な機能

### 1. ファイルシェルフ（一時置き場）
- Finder / エクスプローラーからのドラッグ & ドロップでファイルを一時保持
- Web ブラウザから画像やリンクをドロップ → 自動ダウンロードして実体ファイル化
- 選択テキストのドロップ → `snippet_*.txt` として自動保存
- リストからの **OS ネイティブドラッグアウト**（複数選択対応、Finder ライクな矩形選択・Shift/⌘ 選択）
- クリックで「本物のファイル」としてクリップボードへコピー（macOS: `public.file-url` / Windows: `CF_HDROP`）→ Finder / エクスプローラー / チャットアプリに ⌘V / Ctrl+V でペースト可能
- スペースキーで macOS 純正クイックルック

### 2. クリップボード履歴
- テキスト・画像・ファイルコピーをバックグラウンドで常時監視（500ms ポーリング）
- テキストは生データ + 裏生成 `.txt` の「二刀流」で保持 → クリックで即ペースト、ドラッグでファイル化
- 画像コピーは即 PNG 化してサムネイル表示・ドラッグアウトに対応
- Finder / エクスプローラーでの「ファイルのコピー」も検知してシェルフへ自動追加
- 同一内容の再コピーはカードを増やさず最上位へスタック。リスト上のアイテムをクリックしてコピーした場合も同様に最上位へ移動し、タイムスタンプが更新されます（再コピーと同じ扱い）
- ハイブリッド上限（テキスト 100 件 / 画像 30 件、ファイルも 100 件）+ あふれた裏生成ファイルの自動ディスク削除。気づかないうちに古いものが消えないよう、設定シートに「テキスト 82/100 · 画像 12/30 · ファイル 40/100」の内訳を表示します（ピン留めは上限の対象外）
- パスワードマネージャーなどが「履歴に残さないで」と宣言したコピー（Concealed / Transient 形式）は記録も同期もしない
- **履歴は再起動しても残ります**（`history.json`）。よく使うものは**ピン留め**（右クリック / ⌘P）すると上限や「すべて消去」の対象外になり、先頭に固定されます
- **⌥⌘V**（Windows: Ctrl+Win+V。設定シートでいつでも変更可）でカーソルの近くに履歴のポップアップを出し、選ぶだけでその場にペーストできます（自動ペーストは設定で切れます。macOS ではアクセシビリティの許可が必要）

### 3. マルチデバイス全自動同期
- 各デバイスが軽量 HTTP サーバー（ポート `9095`、`node:http` のみ）を持つ P2P 構成
- ピアは **UDP マルチキャストの自己紹介**（同じ同期キーを持つ相手だけ）で自動発見。届かないネットワークでは設定シートの「いま探す」（/24 スキャン）か静的設定（`sync-config.json`）
- 新着は即時プッシュ、取りこぼしは 20 秒間隔の差分ポーリング（タイムスタンプ比較）で回収
- 3 台以上のメッシュ構成では中継転送により、直接つながっていないピアにも伝播
- 共有シークレットトークンによる認証（不一致は全エンドポイント 401 遮断、`timingSafeEqual` 比較)
- メニューバーから「クリップボードの監視」「ほかのデバイスとの同期」をそれぞれ一時停止できる。接続状況・最終同期時刻・失敗理由は設定シートに、出来事は `bridge.log` に出る
- フォルダは自動で `.zip` 化してから転送し、受信側では **1GB 以内なら自動でフォルダに戻します**（大きいものは zip のまま届き、右クリックの「フォルダとして展開」で戻せます）
- 他のデバイスからの実体が届く前に「同期中」の行が先に出て、届いた時点でその行に差し替わります。並び順と時刻は送信側でシェルフに置いた時刻で揃います
- 大きいファイルの転送中は進捗（% ・受信量・速度）を表示し、しばらく進まなければ「止まっている可能性があります」に切り替えて再試行ボタンを出します。× でいつでも中止できます
- 転送中はパネルを開かなくても分かるよう、メニューバーにも進捗を出します（macOS: アイコン横に `↓42%`、Windows: アイコンのツールチップに「転送中 42%」。複数同時進行なら「N 件転送中」）
- 外部デバイス由来のアイテムには出身デバイス名のチップを表示（ノート / デスクトップのグリフ付き）
- 複数デバイスの履歴が混ざっているときは、右クリックの「このデバイスのアイテムだけ表示」/「"◯◯" のアイテムだけ表示」で絞り込めます。絞り込み中は種別セグメントの下にチップが出て、✕ か Esc で解除できます

### 4. スマート検索
- 展開のたびに検索バーへ自動フォーカス、そのまま打ち始められる
- 検索欄の下の「すべて / ファイル / クリップ」セグメントボタンで種別を絞り込みつつ、そのままキーワード検索も重ねられる
- 検索欄にいたまま ↑↓ で結果を選び、Enter でコピー（Spotlight と同じ操作感）
- キーワード検索中だけフッターにヒット数を表示。file/clip の種別セグメントだけの絞り込みでは出しません（履歴の上限にすぐ頭打ちになり、使い込むほど同じ数字が出るだけで意味を持たなくなるため）

### 5. キーボードとメニュー
- ↑↓ で行移動、Enter = コピー、⌘Enter = Finder に表示、Space = クイックルック、⌫ = リストから外す、Esc = 閉じる
- 右クリックでコンテキストメニュー（コピー / リンクを開く / クイックルック / Finder で表示 / 開く / パスをコピー / ピン留め / リストから外す）。URL のテキストは ⌘Enter でブラウザで開く
- 元ファイルが移動・削除されると「見つかりません」と表示。ドラッグで取り出した直後は「元に戻す」で戻せる
- メニューバーアイコン: クリックで表示 / 非表示、右クリックで「監視を一時停止」「同期を一時停止」「ログイン時に起動」「設定…」「アップデートを確認…」「Bridge を終了」。同じ手動チェックは設定シート内の「アップデートを確認」ボタンからも実行できます
- ショートカットキー（表示 / 非表示、ペーストポップアップ）は設定シートでいつでも変更できます。フィールドをクリックして押したいキーを押すだけです（Ctrl / Alt / ⌘ のいずれかが必要）。Ctrl+Shift+V が他のアプリの「書式なしで貼り付け」と衝突する場合などに使ってください
- Windows では、動画・ゲームなどの全画面表示の上につまみは出ません（設定不要、OS 標準の通知領域と同じ挙動）

| 項目 | 内容 |
|---|---|
| プラットフォーム | macOS / Windows（Linux はベストエフォート）。見た目と動きはそれぞれの OS 標準に合わせています（macOS: すりガラス + スプリング / Windows: Fluent のフライアウト） |

## セットアップ

```bash
npm install
npm start          # 開発起動
```

見た目の確認用に、開発起動時だけ有効な環境変数があります（パッケージ版では無効）。

```bash
BRIDGE_DEV_SEED=1 npm start          # ダミーのアイテムを流し込んで展開したまま保持し、ウインドウ座標を標準出力へ出す
BRIDGE_DEV_SEED=settings npm start   # 同上 + 設定シートを開く
BRIDGE_DEV_SHOT=/tmp/page.png ...    # Renderer の描画内容を PNG に保存
BRIDGE_DEV_EVAL='...' ...            # 展開後に Renderer で JS を実行
```

> **Windows での起動時の注意**: 環境変数 `ELECTRON_RUN_AS_NODE` が設定されているシェルからは GUI が起動しません。設定されている場合は解除してから `npm start` してください。また多重起動はシングルインスタンスロックにより 2 つ目が即終了します。

### ビルド

```bash
npm test             # 純粋関数のテスト (node --test、依存なし)
npm run build        # 現在の OS 向け (Windows: NSIS / Linux: AppImage)
npm run build:mac    # macOS 向け DMG
```

macOS 向けビルドは Hardened Runtime と公証 (`notarize: true`) を有効にしています。`APPLE_ID` / `APPLE_APP_SPECIFIC_PASSWORD` / `APPLE_TEAM_ID` を環境変数で渡すと公証まで行い、無ければ署名なしでスキップされます。

成果物は `dist/` に出力されます。

## 使い方

1. 起動すると、マウスカーソルがあるディスプレイの**右端中央に幅 15px の「つまみ」**が現れます（メニューバーにもアイコンが出ます。Dock には出ません）
2. つまみにマウスを **0.25 秒ほど** 寄せる、ファイルをドラッグして近づける、または **⌥Space**（Windows: Ctrl+Shift+Space）を押すと、幅 320px のシェルフがスプリングでスライド展開します（マルチモニター対応: どのディスプレイの右端でも反応）
3. ファイル / 画像 / テキストをドロップして一時保持、クリックでコピー（チェックマークが出てから自動で閉じ、そのまま ⌘V できます）、ドラッグで取り出し
4. マウスが離れると自動で格納されます。ホバーで開いたときはキーボードフォーカスを奪いません（ホットキーで開いたときだけ検索欄にフォーカスします）

### bridge:// URL スキーム

外部アプリ（macOS のクイックアクション等）からアイテムを追加できます。

```
bridge://add?path=/absolute/path/to/file    # ローカルファイルを追加 (パネルに確認が出て「追加」で載る)
bridge://add?text=https://example.com/x.png # URL → ダウンロードして追加
bridge://add?text=任意のテキスト              # テキスト → .txt 化して追加
```

## デバイス間同期の設定

パネル右下の歯車から開く**設定シート**で、デバイス名・同期キー・自動スキャン・手動ピア・ログイン時起動を変更できます。同期キーは「コピー」ボタンで取り出し、ほかのデバイスの設定シートに貼り付けて揃えてください。接続中のデバイスは同じシートとフッターの緑のドットで確認できます。

設定の実体は初回起動時に `userData` ディレクトリへ自動生成される `sync-config.json` です（`port` の変更はこのファイルを直接編集し、再起動が必要です）。

- macOS: `~/Library/Application Support/bridge/sync-config.json`
- Windows: `%APPDATA%\bridge\sync-config.json`

```json
{
  "port": 9095,
  "peers": ["192.168.1.23", "192.168.1.40:9095"],
  "autoScan": true,
  "myDeviceName": "Win-Desk",
  "iconType": "win_desktop",
  "secretToken": "全デバイスで同じ値に揃える共有キー"
}
```

| キー | 説明 |
|---|---|
| `port` | 同期サーバーの待ち受けポート（既定 `9095`） |
| `peers` | 静的ピア指定（`host` または `host:port`）。自動スキャンで見つからないセグメント越しのピア用 |
| `autoScan` | UDP マルチキャストによる自動発見（既定 `true`）。起動 15 秒後に誰も見つからなければ /24 スキャンを 1 回だけ行う |
| `autoPaste` | ⌘⇧V のポップアップで選んだあと自動でペーストする（既定 `true`） |
| `showSourceApp` | コピー元アプリのアイコンを行に重ねる（macOS 既定 `true` / Windows 既定 `false`。Windows はコピーのたびに PowerShell を起動するため） |
| `myDeviceName` | バッジに表示される自デバイス名（省略時は `os.hostname()`） |
| `iconType` | 旧マウス共有機能で使っていた端末アイコン種別（`win_laptop` / `macbook` / `win_desktop`）。互換のため受け渡しは残しているが、現在の UI では使用しない |
| `secretToken` | **同期認証キー。同期させたいデバイス全台でこの値を一致させてください（設定シートの「同期キー」）。** 未設定なら初回起動時に暗号学的乱数で自動生成されます |

トークンが一致しない相手からのリクエストは全エンドポイントで 401 遮断されるため、同一 LAN に他人の Bridge がいても履歴が混線・漏洩することはありません。

## プロジェクト構成

```
bridge/
├── main.js               # Main プロセス: ウインドウ管理・クリップボード監視・同期サーバー
├── preload.js            # contextBridge による安全な IPC API の公開 (window.bridge.*)
├── renderer.js            # Renderer: リスト UI・検索・選択・D&D・履歴管理
├── index.html             # UI 骨格 (CSP 付き)
├── styles.css              # デザイントークン + すりガラス UI (ライト/ダーク対応)
├── popup.html / popup.js / popup.css  # ⌘⇧V のペースト用ポップアップ
├── tab.html / tab.js / tab.css        # Windows: モニターごとの「つまみ」ウインドウ
├── lib/format.js          # 表示用の純粋関数 (Renderer とテストで共用)
├── lib/sync-utils.js      # 同期・検知の純粋関数 (Main とテストで共用)
├── test/                  # node --test のテスト
├── scripts/start.js       # 開発起動ラッパー (ELECTRON_RUN_AS_NODE を除去して electron を起動)
└── package.json   # electron-builder 設定 (bridge:// スキーム登録を含む)
```

アーキテクチャ・プロトコル・IPC API の詳細仕様は **[SPEC.md](SPEC.md)** を参照してください。

## 設計上の要点

- **セキュリティ**: `contextIsolation: true` / `nodeIntegration: false`。Renderer は `preload.js` が公開する最小限の API のみ使用。CSP で外部リソース読み込みを遮断
- **ディスク保護**: 裏生成ファイル（`clipboard_*.png` / `snippet_*.txt` / `text_*.txt` / 同期受信ファイル / 自動生成 zip）は `sessionTempFiles` で追跡し、履歴あふれ時と終了時に自動削除。**ユーザー自身がドロップした実ファイルには絶対に触れない**。ファイル名の `*` 部分は `2026-09-15_14-30-05` のような読める日時（コロンは Windows で使えないためハイフン区切り）
- **耐障害性**: Renderer クラッシュ時は自動リロード復帰、準備前に届いたアイテムはキューイング。同期のファイル転送失敗はタイムスタンプを進めず次回ポーリングで自動再試行
- **省メモリ**: 同期のファイル転送は送受信ともストリーミング（数 GB でもメモリを圧迫しない）

## 既知の制約

- Windows のファイル関連の検知・書き込みと自動ペーストは、常駐の PowerShell ヘルパー（起動時に 1 プロセス）に依存します。PowerShell が実行できない環境では、コピー検知は先頭 1 件のみ、自動ペーストは無効になります
- Finder 純正の「種類」ラベル（`mdls`）とクイックルックは macOS のみ。他 OS では拡張子ベースの表示にフォールバックします
- 同期チャネルはトークン認証付きですが平文 TCP/HTTP です。信頼できる LAN 内での利用を前提としています
