## Bridge 1.0.0

**Copy on one device. Paste on all of them.**
A small desktop app that lives at the edge of your screen and syncs your files and clipboard history across Macs and Windows PCs on the same LAN. Nothing goes through a server — everything stays on your own network, encrypted with a key only your devices share.

**コピーしたら、もう、届いている。**
画面の端に待機して、同じ LAN の Mac / Windows 間で、ファイルとクリップボードの履歴を同期するデスクトップアプリです。サーバーは経由せず、あなたの端末同士だけで共有する鍵で暗号化して届けます。

### What's in it / できること
- **History & file shelf / 履歴とファイル棚** — Text, images, files and folders you copy or drop are kept and searchable. / コピーしたもの・ドロップしたものが、検索できる履歴として残ります。
- **Quick Paste / クイックペースト** — Call up your history with a shortcut and paste in place, without touching the mouse. / ショートカットで履歴を呼び出して、その場で貼り付け。
- **Sync across devices / デバイス間の同期** — Copy on one, it shows up on the others. Large files show their progress. / 片方でコピーすれば、もう片方に届きます。大きなファイルは進み具合も表示されます。

### Requirements / 動作環境
macOS 12+ / Windows 10+. Devices need to be on the same Wi-Fi / LAN. 同期するには、同じ Wi-Fi / LAN に接続している必要があります。

### Installing / インストール
Bridge is a free app made by an individual and is **not signed** by Apple or Microsoft, so your OS will show a warning the first time. This is expected. 個人開発の無料アプリのため Apple / Microsoft の署名がなく、初回は OS が警告を出します。

- **macOS** — Download the `.dmg`, drag Bridge to Applications. On first launch, right-click the app → **Open**. (On newer macOS, you may need *System Settings → Privacy & Security → Open Anyway*.)
- **Windows** — Run the `.exe`. If “Windows protected your PC” appears, click **More info → Run anyway**.

Details: [Support](https://haruhito767676.github.io/bridge/en/support.html) · The app's interface is currently in Japanese; an English interface is planned. アプリの画面は現在日本語のみです。

### Privacy
No analytics, no accounts, and no network traffic other than syncing between your own devices. The only outside request is the “Check for updates” button, which you press yourself. [Privacy Policy](https://haruhito767676.github.io/bridge/en/privacy.html)
