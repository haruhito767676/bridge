## Bridge 1.0.0

**Copy on one device. Paste on all of them.**

A small desktop app that lives at the edge of your screen and syncs your files and clipboard history across Macs and Windows PCs on the same LAN. Nothing goes through a server — everything stays on your own network, encrypted with a key only your devices share.

### What's in it
- **History & file shelf** — Text, images, files and folders you copy or drop are kept and searchable.
- **Quick Paste** — Call up your history with a shortcut and paste in place, without touching the mouse.
- **Sync across devices** — Copy on one, it shows up on the others. Large files show their progress.

### Requirements
macOS 12+ / Windows 10+. To sync, your devices need to be on the same Wi-Fi / LAN. The app's interface is currently in Japanese; an English interface is planned.

### Installing
Bridge is a free app made by an individual and is **not signed** by Apple or Microsoft, so your OS will show a warning the first time. This is expected.

- **macOS** — Download the `.dmg` and drag Bridge to Applications. On first launch, macOS will refuse to open it: go to *System Settings → Privacy & Security*, scroll down, choose **Open Anyway**, and confirm with Touch ID or your password. You only need to do this once. (On macOS 14 or earlier, right-click the app → **Open** also works.)
- **Windows** — Run the `.exe`. If “Windows protected your PC” appears, click **More info → Run anyway**.

More help: [Support](https://haruhito767676.github.io/bridge/en/support.html)

### Privacy
No analytics, no accounts, and no network traffic other than syncing between your own devices. The only outside request is the “Check for updates” button, which you press yourself. [Privacy Policy](https://haruhito767676.github.io/bridge/en/privacy.html)

## Bridge 1.0.0（日本語）

**コピーしたら、もう、届いている。**

画面の端に待機して、同じ LAN の Mac / Windows 間で、ファイルとクリップボードの履歴を同期するデスクトップアプリです。サーバーは経由せず、あなたの端末同士だけで共有する鍵で暗号化して届けます。

### できること
- **履歴とファイル棚** — コピーしたもの、ドロップしたもの（文字・画像・ファイル・フォルダ）が、検索できる履歴として残ります。
- **クイックペースト** — ショートカットで履歴を呼び出して、その場で貼り付け。マウスは要りません。
- **デバイス間の同期** — 片方でコピーすれば、もう片方に届きます。大きなファイルは、進み具合も表示されます。

### 動作環境
macOS 12 以降 / Windows 10 以降。同期するには、デバイス同士が同じ Wi-Fi / LAN につながっている必要があります。

### インストール
Bridge は個人開発の無料アプリで、Apple / Microsoft の**署名を受けていません**。そのため、初回は OS が警告を出します。これは想定どおりの動作です。

- **macOS** — `.dmg` をダウンロードして、Bridge を Applications へドラッグします。初回の起動では、macOS が開くのを止めます。「システム設定」→「プライバシーとセキュリティ」を開いて、下へスクロールし、**「このまま開く」**を選んで、Touch ID かパスワードで確認してください。一度行えば、次回からは、普通に起動できます。（macOS 14 以前なら、アプリを右クリックして**「開く」**でも開けます。）
- **Windows** — `.exe` を実行します。「WindowsによってPCが保護されました」と出たら、**「詳細情報」→「実行」**を選びます。

困ったときは: [サポート](https://haruhito767676.github.io/bridge/support.html)

### プライバシー
アクセス解析も、アカウントもありません。通信は、あなたの端末同士の同期だけです。外部への通信は、あなたが押す「更新を確認」ボタンだけです。[プライバシーポリシー](https://haruhito767676.github.io/bridge/privacy.html)
