## Bridge 1.0.1

A small maintenance release. No new features. Devices running 1.0.0 and 1.0.1 can sync with each other.

### Changes
- **Update checks now happen only when you ask.** Version 1.0.0 also checked GitHub for a new version automatically, about once a day. That did not match the privacy policy, which says the only outside request is the “Check for updates” button. It now matches: Bridge contacts GitHub only when you press “Check for updates” in the settings sheet, or choose it from the menu bar / tray menu.
- **Quieter, clearer log.** Copying text no longer writes a misleading “could not read the image” line to `bridge.log`, and no longer triggers needless image re-reads.
- **Smaller installer.** Removed leftover code and about 1.6 MB of unused images from the old mouse-sharing feature.

### Updating
Download the installer for your OS from the assets below and install it over your current copy. Your settings and history are kept. Because the app is not signed, macOS may ask for **Open Anyway** again (*System Settings → Privacy & Security*), and Windows may show the “Windows protected your PC” screen again.

There is no automatic update. Pressing “Check for updates” only tells you whether a newer version exists and opens this page.

More help: [Support](https://haruhito767676.github.io/bridge/en/support.html) · [Privacy Policy](https://haruhito767676.github.io/bridge/en/privacy.html)

## Bridge 1.0.1（日本語）

機能の追加はない、小さな保守版です。1.0.0 と 1.0.1 の端末同士でも、そのまま同期できます。

### 変更点
- **更新の確認は、あなたが押したときだけになりました。**1.0.0 は、約 1 日に 1 回、自動で GitHub に新しいバージョンを確認していました。これは、「外部への通信は、あなたが押す『更新を確認』ボタンだけ」と書いたプライバシーポリシーと、合っていませんでした。今回、実際の動きを、ポリシーに合わせました。Bridge が GitHub に通信するのは、設定画面の「アップデートを確認」、またはメニューバー / タスクトレイのメニューから押したときだけです。
- **ログが、静かで分かりやすくなりました。**文字をコピーするたびに、`bridge.log` に「画像を読めず」という紛らわしい行が出ていたのをやめ、無駄な画像の読み直しも、しなくなりました。
- **インストーラーが、少し小さくなりました。**旧マウス共有機能の名残のコードと、使っていなかった画像（約 1.6MB）を、削除しました。

### アップデートの方法
下のファイルから、お使いの OS のインストーラーをダウンロードして、いまのアプリの上から、そのまま入れてください。設定と履歴は、引き継がれます。アプリは署名されていないため、macOS では、もう一度「このまま開く」（「システム設定」→「プライバシーとセキュリティ」）が必要になることがあります。Windows でも、「WindowsによってPCが保護されました」の画面が、もう一度出ることがあります。

自動更新はありません。「アップデートを確認」は、新しいバージョンがあるかを知らせて、このページを開くだけです。
