Bridge 設定 UI — 配置案

いまの設定は 1 本の縦長リスト (高さ約 950px、320×600 のパネルでスクロールが必要) に、12 項目が同じ重さで並んでいます。「つなぐ」ための項目 (同期キー・接続状況) が埋もれているのが、いちばんの問題です。3 つの配置案を、同じ項目・同じ部品 (アプリの styles.css) で並べました。文言は仮です。

案 A — グループ分け + 詳細は別ページ (おすすめ)

先頭に「つながっているか」の状態を置き、その下を「つなぐ / 使いかた / このアプリ」の 3 グループに整理します。IP の手動追加・自動検出・ログ・使用状況のような「困ったとき」の項目は「詳細設定」へ (macOS の設定と同じ、押すと次のページ)。保存ボタンはやめて、変更を自動で保存します。1 画面に収まり、スクロールが要りません。

案 B — セグメントで 3 つに分ける

アプリの検索欄と同じセグメント (つなぐ / 操作 / 詳細) で切り替えます。案 A より 1 画面の情報は少なく、見通しが良い代わりに、ページ移動でなく切り替えなので「戻る」の関係が浅くなります。保存は自動。

案 C — 初回の「つなぐ」ガイド (A / B と組み合わせる)

初めて使うときは、まだ相手がいません。履歴が空のパネルの中に「ほかのデバイスとつなぐ」の手順カードを出して、設定を開かなくても、そこで完結させます。サイトの「はじめかた」の動画も、この流れをそのまま撮れば、言葉と絵がぴったり合います。つながったら、カードは自然に消えます。

気づいたこと (どの案でも)

・保存ボタンは要らない (変更を自動で保存し、デバイス名だけ入力の確定で反映)。・「同期キー」は、見せるより「コピー」「貼り付け」の 2 つのボタンで扱えれば十分 (右側の端末では「貼り付け」が主役)。・説明文は 1 行まで (いまは 2〜3 行が多い)。・「自動ペースト」の文言は、実際の挙動に合わせて言い直したい。・Windows は、これに Windows 用のスキン (既存) を当てる。
