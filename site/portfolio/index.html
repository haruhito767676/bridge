画面の右端に常駐する、ファイルとクリップボードのための小さな橋。マウスを寄せれば現れ、離せば格納される。 同期はクラウドを介さず、同じ Wi-Fi / LAN にいる Mac と Windows が直接つながる。 見た目と操作感は、それぞれの OS の流儀にできるだけ合わせて作った。

what it does

3つの機能をひとつの常駐パネルに

shelf

ファイルシェルフ

Finder / エクスプローラーからドロップして一時的に保持。行をクリックすれば public.file-url（macOS）/ CF_HDROP（Windows）として書き戻し、他のアプリへ「本物のファイル」として ⌘V / Ctrl+V できる。

clipboard

クリップボード履歴

テキスト・画像・ファイルコピーを 500ms ポーリングで常時監視。パスワードマネージャーが宣言する ConcealedType / Transient 形式は記録も同期もしない。

sync

マルチデバイス同期

各デバイスが node:http だけの軽量サーバーを持つ P2P 構成。UDP マルチキャストで自己紹介し合い、見つからなければ /24 スキャン、共有トークンで認証する。

native by platform

Web の移植ではなく、OS ごとに作り分けた

同じ機能でも、macOS と Windows では「らしい」動き方が違う。中身のロジックは共通のまま、見た目と挙動の階層だけ platform 分岐させている。

macOS

  • すりガラス + スプリング展開。ウインドウには vibrancy: 'sidebar' を敷き、つまみへ 0.25 秒寄せるとバネで幅が伸びる
  • セグメントの選択インジケーターが滑る。すべて/ファイル/クリップの切り替えは背景の塗り替えではなく、専用要素を cubic-bezier(0.2, 0.8, 0.2, 1) で横に滑らせている
  • メニューバーは Template アイコン。線画+アルファだけを持たせ、配色は OS の自動着色に委ねる。転送中は setTitle でアイコン横に ↓42%
  • Space でクイックルック。Finder 純正の「種類」ラベルも mdls から取得する

Windows

  • Fluent の Flyout。各モニターの右端に細い「つまみ」ウインドウを常駐させ、フライアウトとして展開する
  • Pivot は下線が瞬時に切り替わる。Fluent の作法に合わせ、macOS 用のスプリングで滑るインジケーターはここでは使わない（意図的に無効化）
  • 進捗はツールチップに。アイコン横にテキストを置けないため、OneDrive などと同じくトレイのツールチップへ「転送中 42%」を出す
  • 常駐ヘルパー経由でクリップボード検知。PowerShell を 1 プロセス常駐させ、CF_HDROP や画像の連番変化を監視する

design log

6つの判断でできた、絞り込み UI

「複数デバイスの履歴が混ざったとき、どう絞り込むか」を作っている途中の実際の変遷。最初から今の形だったわけではない。

01 初期案

「:file」「:clip」とコマンド入力してトークン化する方式で種別を絞り込んでいた。Slack や Linear の検索窓に近い操作感。

02 見直し

Finder / Mail / Spotlight は「打たせる」のではなく「見えるボタンで選ばせる」。file/clip は2〜3択しかなく、コマンド入力は過剰装備と判断。セグメントコントロールに置き換えた。

03 拡張

同期でデバイスが増えると履歴が混ざる。台数分の選択肢を常設ボタンで持つと環境依存で UI が破綻するため、右クリックメニュー「このデバイスのアイテムだけ表示」から入る一時的な絞り込みにした。

04 配置の再検討

絞り込み中のチップを footer に置いていたが、footer は状態表示専用にすべきと考え直し、「今何を見ているか」を示す情報として file/clip セグメントのすぐ下に集約した。

05 配色の修正

彩度の高いアクセント色の塗り + 白文字にしていたが、同系色同士でコントラストが弱く読みにくいと気づいた。アプリ内の他の選択状態と同じ「色でなく塗りの強さで示す」原則に揃え、ニュートラルな地 + 通常の文字色 + 小さいアクセントドットに変更した。

06 副産物

この過程で「footer の件数表示は、履歴の上限にすぐ頭打ちして意味を持たなくなる」ことにも気づき、キーワード検索中だけヒット数を出す仕様に直した。設定シートには上限までの内訳を新設した。

最終形: セグメントの直下にニュートラルな配色のチップ。先頭の青いドットだけがアクセント

specs

仕様

ランタイム
Electron + Node.js。devDependencies は electron / electron-builder のみで実行時の外部依存はゼロ
セキュリティ (Renderer)
contextIsolation: true / nodeIntegration: false。preload.js が公開する最小限の API のみ使用
発見
UDP マルチキャストの自己紹介（同じ同期キーの相手のみ）→ 見つからなければ /24 の並列スキャン
認証
共有シークレットトークンを timingSafeEqual で比較。不一致は全エンドポイント 401
反映
新着は即時プッシュ。取りこぼしはタイムスタンプ比較の差分ポーリングで回収し、3台以上はメッシュ中継
大容量転送
送受信ともストリーミング処理。フォルダは自動 zip 化し、1GB 以内なら受信側で自動展開
履歴の上限は黙って頭打ちになるので、設定シートに内訳を出すようにした
個人開発・ひとりで設計から実装まで
