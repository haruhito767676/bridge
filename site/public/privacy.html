プライバシーポリシー

最終更新日: 2026年10月3日

Bridge は、あなたのコピーした内容やファイルを、開発者を含む誰にも送信しません。

Bridge (以下「本ソフトウェア」) は、クリップボード機能の拡張および複数デバイスの間でクリップボードを同期する無料・オープンソースのアプリケーションです。このページでは、本ソフトウェアおよびこのサイトが、あなたの情報をどう扱っているかを説明します。

1. 本ソフトウェアが扱う情報

1-1. クリップボード履歴・ファイル

コピーした文字・画像・ファイルは、あなたの端末の中だけに保存されます。保存先はあなたのコンピューターのローカルディスクのみで、外部のサーバーやクラウドサービスには一切送信されません。

1-2. 同期する場合

複数の端末で同期を有効にした場合、コピーした内容は次の条件を満たす範囲でのみ、他の端末に送られます。

  • 同じネットワーク (Wi-Fi / LAN) 内にあること
  • 同じ「同期キー」を設定していること

同期キーが一致しない端末には、内容は一切送られません。また、開発者を含む第三者のサーバーを経由することもありません。

通信の暗号化について

同期する内容(メタデータ・ファイル本体とも)は、設定した同期キーから導出した鍵により AES-256-GCM 方式で暗号化されます。同期キーそのものは、通信には流れません。相手を確かめる認証には、同期キーを知っていることの証明 (時刻と使い捨ての乱数を含む HMAC) だけを送り、過去の通信の再送も拒否します。同じネットワーク内であっても、同期キーを知らない第三者が通信内容を読み取ることはできません。

※ただし、通信相手が「本当に意図した端末かどうか」を証明書などで検証する仕組み (PKI) は備えていません。なりすまし対策は同期キーが一致するかどうかに依っているため、信頼できるネットワーク内での利用を前提としています。公衆Wi-Fiなど、見知らぬ人と同じネットワークを共有する環境での利用はお控えください。

1-3. 設定情報

デバイス名や同期キーなどの設定は、あなたの端末内の設定ファイル (sync-config.json) に保存されます。これも外部には送信されません。

2. 本ソフトウェアが行う、唯一の外部通信

本ソフトウェアがインターネット上の外部サービスと通信するのは、設定画面より「更新を確認」ボタンを選択した時のみです。この操作を行うと、GitHub (api.github.com) に最新リリース情報を問い合わせ、ブラウザでリリースページを開きます。

  • この通信は、あなたが明示的に操作した場合にのみ発生します。バックグラウンドや起動時に自動で行われることはありません。
  • 自動的にファイルをダウンロードしたり、インストールしたりすることはありません。
  • これ以外に、本ソフトウェアが外部と通信することはありません。利用状況の収集(アナリティクス)、クラッシュレポートの送信、広告のための通信なども一切行っていません。

3. アカウント・個人情報について

本ソフトウェアの利用にアカウント登録は必要ありません。氏名・メールアドレスなどの個人情報の入力を求めることもありません。

4. このWebページについて

このサイト自体は、アクセス解析ツールや広告用のトラッキングタグを使用していません。Cookieを使った利用者の追跡も行っていません。

5. ソースコードについて

本ソフトウェアはオープンソース (MITライセンス) で、すべてのソースコードを GitHub で公開しています。

6. お問い合わせ

本ポリシーについてのご質問や、記載内容と実際の動作に相違がある場合のご指摘は、GitHubのIssue にてお願いします。

7. このポリシーの変更について

本ソフトウェアの仕様変更に伴い、本ポリシーの内容を更新することがあります。重要な変更がある場合は、このページの「最終更新日」を更新します。

主な変更の履歴

  • 2026年10月3日 (バージョン 2.0.0): 通信の認証を改めました。バージョン 1.x では、認証のために同期キーそのものが通信に含まれており、同じネットワークで通信を観察できる第三者が、同期キーを読み取り、内容を復号できる状態でした。2.0.0 からは、同期キーを通信に流さない方式にしています。1.x と 2.0.0 は、この変更のため、同期できません。信頼できないネットワークで 1.x を使っていた場合は、同期キーを新しいものに変更してください。
