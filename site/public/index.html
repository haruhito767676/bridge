macOS & Windows 用・無料

Mac と Windows、
コピーひとつで繋がる。

ファイルをドロップしてクリップボードに。コピーした内容は、同じ Wi-Fi にいるもう1台にも自動で届く。クラウドは使わない。

GitHub から取得 できることを見る
macOS 12+ ・ Windows 10/11 ・ インストール不要（ソースから起動）

3つのことだけ、うまくやる

ファイルの一時置き場

ドラッグ&ドロップで保持して、必要なときにクリック1つでコピー。他のアプリへそのまま貼り付けられる、本物のファイルとして。

消えないクリップボード履歴

コピーした文字・画像・ファイルを自動で記録。再起動しても残るので、「さっきコピーしたやつ」を探し回らなくていい。

もう1台にも自動で届く

同じ Wi-Fi にいる Mac と Windows が、設定ひとつでお互いを見つけて繋がる。意識せず使えることを目指した。

try it now

触って確かめてみてください

アプリを落とさなくても、ここで動きだけ試せます。検索・切り替え・クリックコピーは全部本物です。

一致するアイテムがありません

コピー先はあなた自身のクリップボードです（このページの外へは送られません）

クラウドを、経由しない。

コピーした内容や送ったファイルは、あなたの Wi-Fi の中だけを通る。外部のサーバーには一切送られない。同期したい相手とだけ、同じ「合言葉」を共有するだけでいい。

smooth by design

Mac では Mac らしく、
Windows では Windows らしく。

見た目を移植しただけのアプリにはしたくなかった。細かい動き方まで、それぞれの OS の標準に合わせている。

  • macOS: すりガラスの質感とバネのような展開アニメーション
  • Windows: Fluent Design のフライアウトと通知領域の作法
  • どちらもキーボードショートカットとクイックルックに対応

small but thoughtful

上限に、気づけるように。

クリップボード履歴には上限があり、古いものから自動で消えていく。それに気づかないまま使うのは不安だと思ったので、設定画面にひと目でわかる内訳を出すようにした。

multi-device

「あれ、どっちの PC だっけ」がなくなる。

2台、3台と繋ぐと履歴は混ざっていく。アイテムを右クリックすれば、そのデバイスから届いたものだけに一時的に絞り込める。出どころも常にチップで一目でわかる。

よくある質問

インターネットに繋がっていなくても使える？

ファイルの一時置き場とクリップボード履歴は単体でも動く。他のデバイスとの同期だけ、同じ Wi-Fi / LAN への接続が必要。

スマートフォンには対応している？

今のところ macOS と Windows のみ。Linux はベストエフォートで動くが、正式には対応していない。

料金はかかる？

無料で、ソースコードも MIT ライセンスで公開している。外部サービスへの課金や登録も一切ない。

コピーした内容はどこかに送信される？

同じ LAN 上の、同じ「同期キー」を持つデバイスにしか送られない。外部のサーバーやクラウドは経由しない。
