      よくある質問

      インターネットに繋がっていなくても使えますか？

      履歴も、ファイルの一時置き場も、それだけならオフラインで動きます。他のデバイスと同期するときだけ、同じ Wi-Fi / LAN が必要です。

      スマートフォンには対応していますか？

      今のところは macOS と Windows に対応しています。スマホ iOS やAndroid には現在対応していません。

      対応OSはなんですか？

      macOS 12 以降と Windows 10 以降に対応しています。Linux 動作はしますが、公式サポートの対象外です。

      料金はかかりますか？

      無料で、ソースコードも MIT ライセンスで公開しています。外部サービスへの課金や登録も一切ありません。

      何台まで同時に繋げられますか？

      台数の上限は設けていません。同じ同期キーを使っている端末であれば、いくつでも繋げることができます。

      ファイルサイズの制限はありますか？

      基本的に上限はありません。ストリーミングで転送するので、数GBのファイルでも問題なく送れます。フォルダだけは1GBを超えると自動では展開されず、zipのまま届きます（右クリックで手動展開できます）。

      Mac 同士や Windows 同士でも使えますか？

      使えます。台数も OS の組み合わせも問いません。Mac 同士でも、Windows 同士でも、Mac と Windows の混在でも、同じ同期キーであれば繋がります。

      1台のPCでしか使いませんが、意味ありますか？

      あります。履歴もファイルの格納も、その場でペーストも、1台だけでそのまま使えます。

      コピーした内容はどこかに送信されますか？

      同じ Wi-Fi / LAN 上の、同じ「同期キー」を持つデバイスにしか送られません。開発者を含む外部のサーバーやクラウドは経由しません。

      通信は暗号化されていますか？

      されています。同期キーから作った鍵で、メタデータもファイル本体もまとめて暗号化しています。同期キーを知らない相手には、同じ Wi-Fi / LAN にいても中身を読み取れません。

      Universal Clipboard や類似ツールと何が違いますか？

      Mac / Windows のどちらでも動き、OS が違う PC 同士も繋げられます。クラウドを経由せず、通信を暗号化していて、無料で、オープンソースです。
