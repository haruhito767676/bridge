Privacy Policy

Last updated: October 7, 2026

Bridge never sends what you copy, or your files, to anyone — including its developer.

Bridge (the “Software”) is a free, open-source application that extends the clipboard and syncs it across your devices. This page explains how the Software and this website handle your information.

1. Information the Software handles

1-1. Clipboard history and files

Text, images and files you copy are stored only on your own device — on your computer’s local disk. They are never sent to any external server or cloud service.

1-2. When syncing

If you turn on syncing across devices, what you copy is sent to other devices only when both of the following are true:

  • They are on the same network (Wi-Fi / LAN)
  • They use the same “sync key”

Devices with a different sync key receive nothing. Nothing passes through any third-party server, including the developer’s.

About encryption in transit

Synced content (both metadata and file contents) is encrypted with AES-256-GCM, using a key derived from the sync key you set. The sync key itself is never sent over the network. To prove that a device knows the key, it sends only a keyed proof (an HMAC that includes a timestamp and a one-time random value), and replays of earlier traffic are rejected. Even on the same network, someone who doesn’t know the sync key cannot read the traffic.

Note: the Software does not verify, with certificates or any other PKI, that the device on the other end is really the one you intended. Protection against impersonation relies on the sync keys matching, so the Software is meant to be used on networks you trust. Please avoid using it on public Wi-Fi or any other network shared with strangers.

About adding a device (pairing)

Only while “Add a new device” is on (at most 2 minutes), this device announces its name and port number to the local network. The announcement does not include the sync key or any hash of it, but other Bridge apps on the same network can see the device name during that time.

The sync key is passed, encrypted, only after you compare the six-digit numbers on both screens and press “Match” on both. If the numbers differ, no key is passed, so a third party who tries to get in between the two devices can be noticed. However, this protection depends on you actually comparing the numbers. If you press “Match” without checking, it does not protect you.

1-3. Settings

Settings such as the device name and the sync key are stored in a settings file (sync-config.json) on your device. This is not sent anywhere either.

2. The only external communication the Software makes

The Software communicates with an external service on the internet only when you choose “Check for updates” (更新を確認) in the settings screen. When you do, it asks GitHub (api.github.com) for the latest release information and opens the release page in your browser.

  • This communication happens only when you explicitly trigger it. It is never done automatically, in the background, or at launch.
  • The Software never downloads or installs anything automatically.
  • Apart from this, the Software does not communicate with anything outside your devices. There is no usage analytics, no crash reporting, and no advertising-related traffic.

3. Accounts and personal information

Using the Software requires no account. It never asks you for personal information such as your name or email address.

4. This website

This website does not use analytics tools or advertising tracking tags, and does not track visitors with cookies.

5. Source code

The Software is open source (MIT License), and all of its source code is published on GitHub.

6. Contact

If you have questions about this policy, or find that what is written here differs from how the Software actually behaves, please let us know by opening an issue on GitHub.

7. Changes to this policy

We may update this policy when the Software’s specifications change. When there is an important change, we will update the “Last updated” date at the top of this page.

Notable changes

  • October 3, 2026 (version 2.0.0): We changed how devices authenticate to each other. In version 1.x, the sync key itself was included in the traffic for authentication, so a third party who could observe traffic on the same network could read the sync key and decrypt the contents. Starting with 2.0.0, the sync key is never sent over the network. Because of this change, 1.x and 2.0.0 cannot sync with each other. If you used 1.x on a network you do not trust, please change your sync key.
  • October 7, 2026 (version 2.1.0): We added pairing. You can share the sync key by comparing a six-digit number on two screens, without typing the key. While a device is waiting to be added, it announces its name and port number to the local network. This mechanism has not been reviewed by a security specialist.
