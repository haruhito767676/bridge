インストール時・起動時に警告が出る

Bridge は個人開発の無料ソフトのため、Apple / Microsoft による署名・審査を受けていません。そのため以下のような警告が出ますが、ソフト自体の問題ではありません。

macOS: 「Mac に損害を与える可能性のあるソフトウェアがないことを Apple が検証できない」

  1. Bridge をダブルクリックして、警告が出たら、いったん閉じる
  2. 「システム設定」→「プライバシーとセキュリティ」を開き、下へスクロールする
  3. 「“Bridge” は…ブロックされました」の横の「このまま開く」を選択
  4. Touch ID またはパスワードで確認すると、開く

一度この方法で開けば、次回からは通常通りダブルクリックで起動できます。macOS 14 以前では、Finder で Bridge を右クリック(または Control+クリック)して「開く」を選んでも開けます。

ターミナルに慣れている場合は、xattr -dr com.apple.quarantine /Applications/Bridge.app を実行しても、同じように開けるようになります。

Windows: 「WindowsによってPCが保護されました」

  1. ダイアログ内の「詳細情報」をクリック
  2. 表示された「実行」ボタンをクリック

他の端末が見つからない

まず、以下を確認してください。

  • 両方の端末が同じ Wi-Fi / LAN に接続されているか
  • 設定シートの「同期キー」が、両方の端末で完全に一致しているか
  • 接続先がゲスト用Wi-Fiになっていないか(端末同士を隔離する設定になっていることが多く、自動発見できません)

それでも見つからない場合は、設定シートの「いま探す」ボタンを押してください。同じネットワーク内を一度スキャンします。

それでも改善しない場合、ネットワーク側でUDPマルチキャスト通信がブロックされている可能性があります。その場合は設定シートの「詳細設定」にある「手動で追加」に、相手のIPアドレスを直接入力することでも接続できます。

同期が遅い・反映されない

  • OS のファイアウォールが Bridge の通信をブロックしていないか確認してください(初回起動時に許可を求めるダイアログが出た場合は「許可」を選択)
  • 設定シートの「詳細設定」にある「接続中のデバイス」に、相手のデバイスが表示されているか確認してください。つながっていない場合は、最後の失敗理由が表示されます

詳しい原因を調べたい場合は、設定シートの「詳細設定」にある「ログを表示」から bridge.log を開いてください。何が起きているか(発見・同期・失敗理由など)が時系列で記録されています。

アンインストールしたい

macOS

  1. メニューバーの Bridge アイコンを右クリックし、「Bridge を終了」を選択
  2. 「アプリケーション」フォルダから Bridge をゴミ箱に入れる

設定や履歴も含めて完全に削除したい場合は、~/Library/Application Support/bridge/ フォルダも削除してください。

Windows

  1. 「設定」→「アプリ」→ 一覧から Bridge を選び「アンインストール」

設定や履歴も含めて完全に削除したい場合は、%APPDATA%\bridge\ フォルダも削除してください。

それでも解決しない場合

上記で解決しない場合は、GitHub の Issue にてご連絡ください。可能であれば、上記の bridge.log の内容と、OS・バージョンを添えていただけると調査がスムーズです。
